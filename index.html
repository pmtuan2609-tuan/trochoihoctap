Biến Giờ Học Thành Đấu Trường Tri Thức

Tải file câu hỏi Word (.docx) và danh sách lớp Excel (.xlsx) để bắt đầu các trò chơi tương tác sôi động: Ai là triệu phú, Đào vàng, Olympia, Vòng quay may mắn.

1. File Bài Tập & Câu Hỏi

Hỗ trợ file Word (.docx) hoặc dùng bộ mẫu

15 câu
Kéo thả file .docx hoặc chọn từ máy tính

Tự động nhận diện: Câu 1: ... A. ... B. ... C. ... D. ... Đáp án: A

Phân loại dạng bài: 5 Dễ 6 Vừa 4 Khó

2. Danh Sách Lớp Học

Tải file Excel (.xlsx / .csv) học sinh

20 Học sinh
Kéo thả file Excel hoặc chọn danh sách lớp

Cột tự nhận diện: STT, Họ và tên, Lớp

Rồng Đỏ
Đại Bàng
Hổ Vàng
Sư Tử Tím
Lớp 10A1 (Mẫu)

5 Trò chơi sẵn sàng
